## 一、为什么需要两个界面

当前状况有两个缺口,它们不是同一件事:

1. **「容器」页还是占位页** —— 导航里有,点进去是"开发中"。
2. **SSH 凭据没有管理入口** —— `servers.ssh_key_path` 字段存在,但界面上无法配置。
   而日志、终端、运维操作全都依赖它。42 那台配的是 `null`,实测 root 登录失败,
   连带终端功能一起不可用。

所以这次要做两处:**容器页(主)+ 服务器 SSH 凭据编辑(前置依赖)**。

**与仪表板的区别**(关键):仪表板上那块是"扫一眼",这里是"查问题"。
所以这里多了:项目/服务器下拉筛选、卡片/表格切换、日志入口、更完整的字段。

### 2.2 两种视图

**卡片视图(默认)** —— 沿用仪表板的网格,增加 hover 操作区

```
┌────────────────────────────────┐
│ ● docker-api-1        运行中   │  状态点 + 名称 + 状态文字(异常才显示)

│ docker · 451 MB                │  项目 · 内存
│ [查看日志]                     │  hover 时出现,仅 admin

```

**表格视图** —— 适合对比数值

| 状态 | 容器 | 镜像 | 项目 | 服务器 | 内存 | 操作 |
|---|---|---|---|---|---|---|
| ● | docker-api-1 | dify-api:1.17.1 | docker | 腾讯云 | 451 MB | 日志 |
| ● | docker-worker-1 | dify-api:1.17.1 | docker | 腾讯云 | 447 MB | 日志 |

用 TanStack Table(项目已依赖),支持列排序。

### 2.3 日志抽屉(核心交互)

点「查看日志」从右侧滑出抽屉,**不跳页**(保留列表上下文):

```
                                    ┌──────────────────────────────────┐
                                    │ docker-api-1            [×]      │
                                    │ 腾讯云-42.193.241.34 · docker    │
                                    ├──────────────────────────────────┤
                                    │ [最近 15 分钟 ▾]  [跟随 ●] [清屏]│
                                    ├──────────────────────────────────┤
                                    │ 23:41:02 INFO 200 OK             │
                                    │ 23:41:03 INFO 200 OK             │
                                    │ 23:41:05 ERROR timeout           │  ← 自动滚动
                                    │ 23:41:06 INFO 200 OK             │
                                    │ ...                              │
                                    └──────────────────────────────────┘
```

**要素:**
- 时间范围下拉:`15 分钟 / 1 小时 / 6 小时 / 24 小时`
- 「跟随」开关:开 = 实时流自动滚到底;关 = 暂停滚动(用户向上翻时自动取消)
- 等宽字体,`ERROR`/`WARN` 关键词高亮
- 底部状态条:`已连接 · 共 342 行` / `连接中断,重连中…`

**权限**:非 admin 不显示「查看日志」按钮,抽屉也不可达。

### 2.4 空状态与失败态

| 场景 | 展示 |
|---|---|
| 没有容器 | 「还没有采集到任何容器」+ 说明「需先在部署页登记项目」 |
| 筛选无结果 | 「没有匹配的容器」+ 清除筛选链接 |
| 日志:服务器未配 SSH | 「该服务器未配置 SSH 凭据」+ **[去配置]** 跳转 |
| 日志:SSH 失败 | 「无法连接:Permission denied」+ 显示具体错误 |
| 日志:空 | 「该时间范围内没有日志」 |

## 三、SSH 凭据编辑(前置依赖)

### 3.1 位置

在「服务器」面板,每行的操作区加一个 **「凭据」** 按钮(仅 admin),打开对话框。

### 3.2 对话框设计

```
┌─────────────────────────────────────────────┐
│ SSH 凭据 · 腾讯云-42.193.241.34        [×]  │
├─────────────────────────────────────────────┤
│ 连接地址   42.193.241.34                    │
│                                             │
│ 用户名     [root          ]                 │  ← 默认 root,可改
│ 端口       [22            ]                 │
│                                             │
│ 私钥路径   [/root/.ssh/opsdeck_ed25519    ] │  ← 容器内路径
│            ⓘ 留空则使用 ~/.ssh/id_ed25519   │
│                                             │
│ 终端授权   [ 开关 ]  允许通过 Web 终端登录  │
├─────────────────────────────────────────────┤
│ [测试连接]              [取消] [保存]       │
└─────────────────────────────────────────────┘
```

**「测试连接」** 是关键:点一下实际执行 `ssh root@ip 'echo ok'`,
返回成功/失败原因,避免保存了错配置还不知道。

### 3.3 字段与模型变更

| 字段 | 现状 | 变更 |
|---|---|---|
| `ssh_user` | **不存在** | **新增**,默认 `root` |
| `ssh_port` | 已有 | 不变 |
| `ssh_key_path` | 已有 | 界面上可选填 |
| `terminal_enabled` | 已有 | 已有开关,移入此对话框 |

需要:1 个 alembic 迁移(加 `ssh_user` 列)+ schema 更新。
